# BetaTask
BetaTask is a lightweight, command-based environment designed to bridge the gap between high-level OS monitoring and low-level hardware control.
## What does it do?
BetaTask was made to simplify the command line when doing basic file management, system monitoring, and more.  
The goal of BetaTask is to take the commands and architecture from the CLI-based bash script and bring them to more devices and languages, such as the ESP32.  

## Supported Systems:
### Systems with a stable version:
 - Raspberry Pi (Debian Linux) (bash)
### Systems with an unstable version:
(none)

(none)
